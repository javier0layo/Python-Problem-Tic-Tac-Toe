# Python-Problem-Tic-Tac-Toe
**Objective:** The primary objective of this code is to implement a simple command-line Tic Tac Toe game for two players. It allows users to take turns marking a 3x3 grid with their respective symbols (X and O), checking for a winner after each move, and ultimately determining the outcome of the game (win, lose, or tie).
Goals:

**Grid Representation:**
Create a visual representation of the Tic Tac Toe board using a 2D list.
Display the grid with clear formatting, including borders to delineate each cell.
Game Flow Control:

Implement a loop that allows players to take turns until the game is over.
Ensure that players can only make valid moves (e.g., within the bounds of the grid and in empty spaces).

**User Interaction:**
Prompt players for their moves by asking for row and column inputs.
Validate user inputs to prevent invalid moves and provide informative error messages when necessary.
Winning Logic:

Check for winning conditions after each turn by examining rows, columns, and diagonals.
Declare the winner when a player has successfully placed three of their marks in a row, column, or diagonal.

**Game Outcome:**
Determine when the game ends due to a win or a tie (after all 9 spaces have been filled without a winner).
Display a message indicating the result of the game (which player won or if it was a tie).

**Code Structure and Readability:**
Organize the code into functions for clarity and modularity, making it easier to understand and maintain.
Include comments throughout the code to explain the purpose of different sections and improve overall readability.
